# מחקר מימוש — הצעות מחיר אסטרטג

תאריך: 26 בספטמבר 2026. היקף: ייצוא, הדפסה, עברית וטפסים במערכת הסטטית הקיימת. המחקר מבוסס על קריאת הקוד ועמודי תיעוד רשמיים; לא בוצעה כאן בדיקת דפדפן או הפקת PDF.

## 1. להבחין בין הדפסה, PDF וקובץ HTML

`window.print()` פותח את חלון ההדפסה של המסמך הנוכחי ואינו מחזיר תוצאת שמירה. קריאה מוצלחת לפונקציה אינה ראיה לכך שנוצר PDF. [MDN — Window.print](https://developer.mozilla.org/en-US/docs/Web/API/Window/print).

בקוד הנוכחי זו הפעולה של כפתור ההדפסה. לכן הניסוח צריך לתאר פתיחת הדפסה ובחירת שמירה כ־PDF דרך הדפדפן, בלי הודעת ״PDF נשמר״. יש לבדוק בנפרד את תצוגת ההדפסה ואת הקובץ שנשמר, לרבות עברית, סכומים, לוגו והצעה ארוכה. מראה הדפסה צריך להישאר בהיר גם אם ממשק העבודה כהה. אלו המלצות למוצר, ולא הבטחת תמיכה של הדפדפן הפנימי.

## 2. ייצוא HTML הוא מסלול נפרד, ויש לתאר אותו במדויק

מאפיין `download` תומך בכתובות מאותו מקור ובכתובות `blob:` ו־`data:`. אופן הטיפול בהורדה משתנה לפי הדפדפן וההגדרות: ייתכנו שמירה, בקשת אישור או פתיחת הקובץ. [MDN — קישורים והורדות](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#download).

במימוש הנוכחי נוצר Blob מסוג HTML, עם העיצוב מוטמע, בשם בעל סיומת HTML. לכן מומלץ לשנות את ״הורדת ההצעה״ ל״הורדת קובץ HTML״, ולהשאיר את ההדפסה כפעולה נפרדת. יש לבדוק את הקובץ שהתקבל ולוודא שהוא נפתח מחוץ למערכת עם הלוגו והתכולה הנכונה. היעדר אירוע הורדה בכלי הבדיקה אינו מוכיח שהקובץ נשמר או שההורדה נכשלה. אין להבטיח השלמה בלי ראיה נצפית.

## 3. עברית וסמנטיקה לפני אפקטים חזותיים

W3C ממליץ להגדיר כיוון בסיס ב־HTML באמצעות `dir`, ולהשתמש במאפייני CSS לוגיים כגון `start` ו־`end`. כיוון RTL משנה גם את סדר עמודות הטבלה. [W3C — מבנה מסמך מימין לשמאל](https://www.w3.org/International/questions/qa-html-dir).

במערכת ובמסמך המיוצא כבר מוגדרים `lang="he"` ו־`dir="rtl"`, וטבלת המחירים כוללת כותרות עמודה ושורה. לשמר זאת בזמן העיצוב ולבדוק טקסט עברי עם שמות חבילות באנגלית ומחירים. בטלפון צר יש לשמור על התאמה ברורה בין רכיב, מחיר חודשי ומחיר שנתי; אין להפוך טבלה לכרטיסים חזותיים בלי לשמר את הקשרים.

קבוצת פקדים צריכה קיבוץ חזותי וסמנטי. `fieldset` ו־`legend` נותנים לקבוצת בחירה שם משותף; כותרת מודגשת בלבד אינה אותה סמנטיקה. [W3C WAI — קיבוץ פקדים](https://www.w3.org/WAI/tutorials/forms/grouping/).

ממצא מקריאת הקוד: בחירת המשפיענים בפודקאסט משתמשת בפקדי רדיו טבעיים, אך השאלה שמעליהם היא `strong` ללא קבוצת `fieldset`. מומלץ לעטוף את האפשרויות בקבוצה עם `legend` קצר. אין צורך לשנות את המראה כדי לשפר את הקשר הנגיש.

| עדיפות | שינוי או מגבלה | ראיית קבלה |
|---|---|---|
| ראשונה | להפריד במפורש הורדת HTML מהדפסה ושמירת PDF דרך הדפדפן | הכפתורים מתארים את הפעולה המדויקת; אין הודעת שמירה שאינה מאומתת |
| ראשונה | לוודא תוצר בפועל בדפדפן הנתמך | קובץ שהורד נפתח עם בחירות, סכומים ולוגו; PDF שנשמר נבדק גם בהצעה ארוכה. תמיכה בדפדפן הפנימי נשארת לא מאומתת עד בדיקה שם |
| שנייה | לקבץ סמנטית את בחירת המשפיענים ולשמר RTL במובייל ובהצעה | הקבוצה מזוהה בשמה, הבחירה נגישה במקלדת ואין ערבוב עמודות או סכומים ברוחב צר |
