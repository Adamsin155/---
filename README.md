# סוכנים ומסמכים — מערכת הצעות המחיר של אסטרטג

פרופילי סוכנים ומסמכי מקור לעבודה על מערכת הצעות המחיר לאנשי מכירות. הפרופילים הם הוראות לשימוש חוזר. שמירתם אינה מפעילה שירות או עבודה ברקע.

## מבנה

```
.claude/agents/
  ux.md          חוויית משתמש: רצף, ניסוח, מניעת טעויות
  design.md      עיצוב: היררכיה חזותית, מותג, הצעה מודפסת
  tech.md        טכנולוגיה: מימוש, חישובים, ולידציה, אבטחה
  qa.md          איכות: אימות עצמאי (ללא עריכה)
  research.md    מחקר: מקורות והמלצות (קריאה בלבד)
docs/
  pricing-rules.md   מקור האמת: חבילות, מחירים, כמויות, זכאות, מקרי קבלה
  roles.md           חלוקת האחריות בין הסוכנים
  brand/
    implementation-research.md
    brand-guide.md       (טרם הועלה)
    design-research.md   (טרם הועלה)
```

## הפעלה ב־Claude Code

כשהתיקייה נמצאת בפרויקט, הסוכנים זמינים לפי השם, למשל: ״הפעל את סוכן ה־qa על הגרסה הנוכחית״.

## כללים

- שינוי מחיר, כמות או זכאות נעשה רק ב־[docs/pricing-rules.md](docs/pricing-rules.md).
- שינוי בחלוקת האחריות נעשה רק ב־[docs/roles.md](docs/roles.md).
