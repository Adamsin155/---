# תדריך לתסריט

לשלוח למשתמש **רק את השאלות שעוד לא נענו בשיחה**, ברשימה אחת. אם הוא עונה "תחליט אתה", ממשיכים עם הנחות וכותבים אותן בראש הפלט.

```
כדי לכתוב תסריט שעובד אני צריך עוד כמה פרטים:

1. העסק: מה הוא, איפה, ומה הדבר האחד שבאמת מייחד אותו? (עובדה, לא סיסמה)
2. ההצעה במודעה: מה מוכרים? יש מחיר, הטבה או דדליין אמיתי?
3. הקהל: מי? מכירים כבר את העסק או שומעים עליו לראשונה? פונים בלשון זכר, נקבה או רבים?
4. היעד: לידים / הודעות בוואטסאפ / הזמנות / רכישה / הגעה לעסק?
5. מי מול המצלמה: נטלי, סמיון מישל ודניס, בעל העסק, לקוח, או רק קריינות?
6. פורמט: רילס / סטורי / פיד? כמה שניות?
7. יש משהו שאסור להגיד או שהלקוח לא רוצה?
```

## מה אפשר להניח בלי לשאול
- פורמט: רילס 9:16, 20–30 שניות
- פנייה: רבים
- קהל: קר (לא מכיר את העסק), באזור של העסק
- כמות: 3 זוויות × 3 הוקים

## מה אסור להניח
- מחירים, הטבות, מועדים
- מספרים (לקוחות, שנים, מנות, דירוגים)
- ציטוטים של לקוחות
- שמשפיען מסוים משתתף, אם לא נאמר
